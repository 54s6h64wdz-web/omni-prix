Twitoo

Vidéos Twitter / X, sans pub

Comment ça marche
  1. Dans l'app X, sur le tweet : Partager → Copier le lien.
  2. Ici : Coller, puis Trouver la vidéo.
  3. Choisis la qualité. Une fois chargée, touche Enregistrer puis Enregistrer la vidéo pour l'avoir dans Photos.
  4. Astuce : dans Safari, Partager → Sur l'écran d'accueil pour l'avoir comme une vraie app.
Aucune pub, aucun traqueur. Les tweets privés ne sont pas accessibles.
